# 📦 Librería de Estructuras de Datos y TADs en C

Repositorio orientado al estudio e implementación desde cero de **Estructuras de Datos** y **Tipos Abstractos de Datos (TADs)** utilizando lenguaje **C**.

El proyecto está enfocado en aplicar conceptos fundamentales de ciencias de la computación, tales como **gestión dinámica de memoria** (`malloc`, `free`), **manipulación de punteros**, y **optimización de algoritmos**.

---

### 🛠️ Estructuras Implementadas

* **Pilas (Stacks):** LIFO mediante arreglos dinámicos y listas enlazadas.
* **Colas (Queues):** FIFO con nodos enlazados y punteros a inicio/fin.
* **Listas Enlazadas:** Simples, dobles y circulares con operaciones de inserción, eliminación y búsqueda.
* **Árboles (Trees):** Árboles Binarios de Búsqueda (BST) y recorridos (Inorder, Preorder, Postorder).

---

### 🚀 Conceptos Clave Aplicados

* Modularización mediante archivos de cabecera (`.h`) e implementación (`.c`).
* Manejo estricto de memoria y prevención de *memory leaks*.
* Análisis de complejidad temporal y espacial (Notación Big O).
